## Reproducing the manuscript and supplementary results

This repository contains the code used to reproduce the results reported in the manuscript and Supplementary Materials for *Amortized Bayesian Inference for Boundary Detection on Heterogeneous Spatial Graphs*.

The workflow has three main blocks:

1. **Simulation experiments** validating ABI-DAGAR under the proposed Poisson-DAGAR boundary-detection model. These include parameter recovery, posterior calibration, boundary-probability diagnostics, parameter-posterior replicated-data checks, a closely aligned DAGAR MCMC comparison, computation summaries, and the ablation study of summary statistics.
2. **Real-data analyses** applying the same trained ABI-DAGAR approximation to Greater Glasgow respiratory-disease hospitalizations, California lung-cancer incidence, and South Korean tracheal, bronchial, and lung-cancer mortality, with comparisons against `CARBayes` and a dataset-specific DAGAR MCMC sampler.
3. **Supplementary diagnostics and benchmark analyses** extending the main validation with additional calibration, replicated-data, ablation, runtime, provenance, and real-data comparator results.

The DAGAR MCMC implementation uses the same likelihood, DAGAR construction, scalar threshold, and fixed identity ordering as the simulator. Its intercept and variance priors differ, as documented in the benchmark code and Supplementary Materials. The replicated-data checks draw a new latent field from its conditional prior for each scalar posterior draw; they are not full latent-field posterior predictive checks.

Analysis figures are written next to the block that generated them. Tracked
manuscript-ready standalone figures and standardized map panels are collected
in `Figure Generation/Images`. Numerical summaries for manuscript and
supplementary tables are stored in the CSV outputs listed below.

The repository retains the compact reference outputs used in the manuscript so
that reported values can be checked without repeating every long stochastic
run. Large or redundant intermediate objects are excluded. With the exception
of the historical real-data wall-clock references noted below, retained
analysis outputs can be regenerated by the listed workflows, which create
their destination directories automatically when run from a fresh clone.

### Environment, licensing, and data access

Create the recorded Python environment with:

```bash
conda env create -f environment.yml
conda activate abi-boundary-detection
```

The R analyses used R 4.4.1 with `CARBayes` 6.1.1, `CARBayesdata` 3.0,
`sf` 1.0-21, `spdep` 1.3-13, `Rcpp` 1.0.12, `RcppArmadillo` 15.2.3-1,
`coda` 0.19-4.1, and `tictoc` 1.2.1. Run `Rscript install_r_dependencies.R`
to install missing packages.

The code is released under the [MIT License](LICENSE). Dataset sources and
availability are documented in [DATA_ACCESS.md](DATA_ACCESS.md).

### 5. Run the real-data ABI-DAGAR and `CARBayes` analyses

#### Data provenance and preparation details

**Greater Glasgow.** The analysis-ready file
`$REAL/Data/respiratory_data_glasgow.gpkg` reproduces the 134 rows and variables
of `CARBayesdata::respiratorydata`, joined by Intermediate Zone identifier to
the `GGHB.IZ` polygons. The analysis used `CARBayes` 6.1.1 and
`CARBayesdata` 3.0. The source variables describe 2010 respiratory-disease
hospitalizations north of the River Clyde, expected counts based on
Scotland-wide respiratory hospitalization rates, and `incomedep`, the
percentage of residents defined as income deprived. The adjacency matrix in
`$REAL/Data/adjacency_matrix_glasgow.csv` was constructed from the joined
polygons with `spdep::poly2nb` and `nb2mat`.

**California.** The file `$REAL/Data/respiratory_data_california.gpkg`
contains the processed 2012--2016 county-level cancer-incidence data analyzed
by Gao et al. and Aiello and Banerjee; the underlying incidence source is SEER.
See [DATA_ACCESS.md](DATA_ACCESS.md) for the expected schema and source access
information. Expected lung-cancer counts were formed by
applying statewide age-sex-specific incidence rates to county populations and
summing over 19 age groups and two sexes. The smoking measure covers 2014--2016
and comes from *California Tobacco Facts and Figures 2018*. The preparation
workflow constructs county polygons from the R `maps` package and defines
queen neighbors using `spdep::poly2nb`; the resulting matrix is stored as
`$REAL/Data/adjacency_matrix_california.csv`.

**South Korea.** The folder `$REAL/Data/South_Korea` contains the complete
download and preparation workflow. `download_south_korea_data.py` retrieves
municipal deaths from KOSIS table `DT_1B34E13`, municipal midyear populations
by sex and age from `DT_1B040M5`, national cause-specific deaths from
`DT_1B34E11`, and the KDCA Community Health Status Indicators workbook.
`prepare_south_korea_data.py` constructs expected counts from annual national
sex-age-specific rates, averages age-standardized current-smoking prevalence
over 2015--2019, skips blank source cells, and uses a reported parent-city value
only when a municipality-specific value is unavailable. It also handles the
2018 Incheon Nam-gu/Michuhol-gu rename explicitly.

The South Korean geometries use the May 2019 `TL_SCCO_SIG` municipal boundary
layer. Boundary and KOSIS identifiers are linked through
`south_korea_kosis_crosswalk.csv`, and queen contiguity is defined from polygon
intersections. The full 250-unit graph has components of sizes 241, 2, and
seven singletons. The analysis-ready files
`mortality_data_south_korea.gpkg` and `adjacency_matrix_south_korea.csv` retain
the 241-unit largest component; the nine omitted units are listed in
`excluded_island_municipalities.csv`. SHA-256 checksums for downloaded archives
are stored in `raw/checksums.csv`, with additional provenance recorded in
`south_korea_data_manifest.json` and the folder-level `README.md`.

To download the archived source files and rebuild the South Korean
analysis-ready inputs, run from the repository root:

```bash
python "Real Data Analysis/Data/South_Korea/download_south_korea_data.py"
python "Real Data Analysis/Data/South_Korea/prepare_south_korea_data.py"
```

Across the three applications, GeoPackage row order is matched exactly to the
corresponding adjacency-matrix row and column order. The matrices are binary,
symmetric, and have zero diagonals, and the analysis variables contain no
missing values. Both Python and R center each boundary-driving covariate by its
empirical mean and divide by its population standard deviation with denominator
`N`, ensuring that ABI-DAGAR and the dataset-specific comparators use the same
dissimilarity convention.

### Application output index

The current manuscript uses Greater Glasgow, California, and South Korea. The
main exploratory inputs are produced by `$REAL/exploratory_analysis.ipynb` in
`$REAL/results_exploratory_analysis`, including
`application_shared_model_diagnostics.png`,
`application_observed_expected_relationships.png`,
`application_covariate_risk_relationships.png`, and
`application_numbered_boundary_overviews.png`.

The main ABI boundary-probability maps are
`glasgow_boundary_probability_map.png`,
`california_boundary_probability_map.png`, and
`south_korea_boundary_probability_map.png` in the corresponding `$REAL_CAR`
application folders. The `CARBayes` agreement maps use the same application
folders and replace `boundary_probability_map` with `boundary_agreement`.
The DAGAR MCMC agreement maps are in the corresponding `$REAL_DAGAR` folders
and end in `boundary_agreement_dagarbayes.png`.

Numerical sources are the per-application `parameter_summary_comparison.csv`,
`edge_metrics.csv`, `edge_comparison.csv`, `risk_metrics.csv`, and
`risk_comparison.csv` files, together with the combined metric CSVs at the root
of `$REAL_CAR` and `$REAL_DAGAR`. Standalone diagrams and standardized copies
of reported map panels are generated under `$FIG`; they are presentation
outputs rather than independent numerical sources.
